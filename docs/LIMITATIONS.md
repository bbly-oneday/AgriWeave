# 1.0.0适用范围与剩余问题

本版本定位为研究用几何参考路线和配置时间效率估算。可用来比较田块形态和规划方案，不具备直接驱动实车自动作业的认证。

| 已知事项 | 解释及使用要求 |
|---|---|
| 350田中85田接缝EXCESS_OVERLAP | 跨区重复作业超过既定预算；保留覆盖问题和状态，不能称作质量PASS |
| 350田中21田驾驶风格REVIEW | 几何路线已经连通，局部驾驶习惯指标仍需复核 |
| physical_vehicle_certification=NOT_EVALUATED | 默认参考策略未认证真实转弯半径、连续转向、挡位、机具动态和压苗 |
| headland_coverage_status=NOT_EVALUATED | 有序田头参考线及其估算时间不证明田头真实作业覆盖 |
| 缺少真实进出口及实测参数 | 不捏造田门、朝向、GNSS轨迹和停顿时间；结果是配置条件下的推算 |
| 大规模容量尚未验证 | 350田不证明十万级容量。条带阶段仍批量聚合输入与结果，应按500～1000田分片，并做代表性1万田服务器压力验证 |
| 单田内部串行 | 多田通过进程并行；没有混合线程提速证据，资源探测仅是启动快照 |
| 搜索有界 | SEARCH_LIMITED、超时和搜索失败不证明物理不可达；缺少完整路线的效率保持NULL |
| 投影原始输入的整田面显示坐标 | 当前精简导出直接将输入面写入EPSG:4326图层，米制原始输入会产生错位。使用normalize_field_input.py先将输入真实转换为EPSG:4326；公开样例也统一此CRS。该限制在发布人工流程测试中检出，未通过修改旧源码摘要掩盖 |

参考联通、导出/账本审计、主体覆盖、接缝质量、驾驶风格和实车认证分别判断。`reference_acceptance_passed=true`可以与`acceptance_passed=false`并存，不应隐藏其中任何一个。
